# ERFAN Site — نسخه آغازین

این نسخه یک اسکلت اجرایی با رابط فارسی و راست‌چین است و شامل ثبت‌نام/ورود، پروفایل، تایم‌لاین، لایک، نظر، استوری ۲۴ ساعته، جست‌وجوی کاربران، دنبال‌کردن، ساخت گروه/کانال، پیام‌رسان گروهی بلادرنگ و پنل مدیریت اولیه است.

## اجرای محلی
1. Node.js نسخه 20 یا جدیدتر نصب کن.
2. در پوشه پروژه دستور `npm install` را اجرا کن.
3. فایل `.env.example` را به `.env` تغییر نام بده.
4. مقدار `SESSION_SECRET` را با یک رشته طولانی و تصادفی جایگزین کن.
5. `ADMIN_USERNAME` و `ADMIN_PASSWORD` را برای ساخت مدیر اولیه تنظیم کن.
6. دستور `npm start` را اجرا کن و `http://localhost:3000` را باز کن.

## استقرار روی Render
- یک Web Service جدید بساز و پروژه را از GitHub وصل کن.
- Build Command: `npm install`
- Start Command: `npm start`
- در Environment Variables مقادیر `.env.example` را وارد کن.
- برای حفظ SQLite و نشست‌ها، یک Persistent Disk به مسیر `/opt/render/project/src/data` وصل کن.
- SQLite روی دیسک پایدار مناسب پروژه کوچک/آزمایشی است؛ برای مقیاس بزرگ و چند نمونه سرور، PostgreSQL و ذخیره‌سازی فایل جداگانه پیشنهاد می‌شود.

## نکات مهم
- رمزها با bcrypt هش می‌شوند و درخواست‌های ورود/ثبت‌نام محدودسازی نرخ دارند.
- رمز مدیر را در کد قرار نده؛ فقط از متغیر محیطی استفاده کن.
- این نسخه MVP است: پیام خصوصی یک‌به‌یک، بارگذاری واقعی عکس/ویدئو، بازیابی رمز، تأیید ایمیل، اعلان‌های مرورگر، ابزارهای کامل مدیریت و تست امنیتی هنوز نیازمند مرحله توسعه‌اند.
- در نسخه فعلی تصویر پروفایل فقط به‌صورت URL ذخیره می‌شود؛ فایل آپلود نمی‌شود.
